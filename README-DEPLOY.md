# Seiryun — The Rogue Cultivator

A static, multi-page character archive. No paid hosting or build tools required.

## Preview locally
Open `index.html` in a browser. All pages are plain HTML/CSS and work without a server.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com.
2. Create a new **public** repository named `seiryun-archive`.
3. Upload the contents of this folder (the HTML files, `style.css`, `script.js`, and `assets/`) to the repository root. Do not upload the outer ZIP file itself.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then press **Save**.
7. Wait a minute or two. GitHub will show the public address, normally:
   `https://YOUR-USERNAME.github.io/seiryun-archive/`

## Updating the site
Edit the relevant `.html` file, or replace images inside `assets/` while keeping their filenames. Upload the changed files to the same repository. GitHub Pages republishes automatically.

## Notes
- Hosting is free for a public repository on GitHub Pages. A custom domain is optional and costs extra.
- The site is an unofficial fan-made EVE Online character archive and is not affiliated with CCP Games.
- The biography is based on the character concept developed with the user. The Imperial authority who bestowed the name Seiryun is fictional roleplay, not an established EVE lore event.
- Fonts load from Google Fonts when internet access is available; fallback fonts are included.
